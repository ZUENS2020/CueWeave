# CueWeave v0.1.1 — Windows 修复版 / Windows fixes

## 中文

- 改善小窗口布局、工具栏、元数据展示及时间轴配色。
- 修复快捷键路由、输入框焦点、撤销/重做和保存状态问题。
- 修复播放时钟重复采样引起的错误跳转，以及拖拽缩放和倍率显示问题。
- Windows 实机验证新建、打开、歌词插入、选择、播放和导出；47 项核心测试与 32 项 Windows 测试通过。
- 导出 MP3 的音频载荷与源文件逐字节一致，无重新编码。

下载并完整解压 Windows x64 ZIP，再运行 `CueWeave.Windows.exe`，不要仅移动 EXE。
本次仅提供更新后的 Windows 包；macOS 用户可继续使用 v0.1.0 的包。
AI 联网翻译和对齐未实测（验收机未配置密钥）；本次不宣称完成全部功能或所有显示环境验收。

## English

- Improved compact layouts, toolbars, metadata presentation and timeline colors.
- Fixed shortcut routing, editor focus, undo/redo and save-state handling.
- Fixed false playback seeks from duplicate clock sampling, drag zoom and zoom labels.
- Verified create/open, lyric insertion, selection, playback and export on Windows hardware; 47 core and 32 Windows tests passed.
- Exported MP3 audio payload is byte-identical to its source, without re-encoding.

Extract the complete Windows x64 ZIP and run `CueWeave.Windows.exe`; do not move the executable alone.
This release provides the updated Windows package only. macOS users can continue using the v0.1.0 package.
Live AI translation/alignment was not tested because the acceptance host has no API keys. This is not a claim of exhaustive feature or display-environment coverage.
